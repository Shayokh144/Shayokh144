## About Me

I'm an iOS engineer at [Nimble](https://nimblehq.co/) (since 2022), where I build high-traffic consumer apps such as [The Pizza Company](https://apps.apple.com/th/app/the-pizza-company-1112/id1033213872) and [Jollibee](https://apps.apple.com/us/app/jollibee-order-rewards/id1562215526), and production Flutter apps such as [OKYA](https://okya.co/en/) and [easyHotel](https://apps.apple.com/th/app/easyhotel-book-value-stays/id1492316252). Before that, I spent four years at [Samsung R&D Institute Bangladesh](https://research.samsung.com/srbd) building the [Galaxy Watch](https://apps.apple.com/in/app/samsung-galaxy-watch-gear-s/id1117310635) and [Galaxy Fit](https://apps.apple.com/in/app/samsung-galaxy-fit-gear-fit/id1117312500) companion iOS apps over BLE.

I care about security, clean architecture, accessibility, and code that stays easy to change. Lately I've also been working on AI-assisted development and LLM prompt evaluation.

## Highlights

**iOS**
- Implemented SSL pinning, mTLS, and HMAC request signing on high-traffic production apps
- Built a modular SPM library (UI, networking, data) shared across 3 Jollibee iOS apps

- Refactored legacy modules to MVVM and Clean Architecture, with 100% unit test coverage on the business logic
- Shipped VoiceOver, Dynamic Type, and Full Keyboard Access support in client apps

**Flutter**

- Migrated [OKYA](https://okya.co/en/) login to OAuth 2 with PKCE, removing the client secret from the app
- Fixed a memory leak behind out-of-memory crashes on OKYA's production kiosk devices

**Samsung**
- Built BLE integrations for the Galaxy Watch and Galaxy Fit companion apps
- Automated the localization workflow, cutting manual effort by 94%
- Named Icon of the Month (2020)

**AI tooling**
- Introduced Promptfoo-based prompt evaluation for Nimble's internal AI agent framework, running in GitHub Actions CI
