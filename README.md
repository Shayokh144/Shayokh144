## About Me

I build consumer iOS apps at Nimble, including apps for The Pizza Company and Jollibee. Before that, at Samsung R&D, I built BLE integrations for Galaxy Watch and Galaxy Fit. I care most about clean architecture, security, accessibility, and code that stays easy to change.

Right now I'm working on reusable mobile modules and exploring AI agent skills and developer tooling.
